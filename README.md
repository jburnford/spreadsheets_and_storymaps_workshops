# HIST 243 workshops: spreadsheets and StoryMaps

Self-paced workshops for HIST 243, *Reverberations of the Industrial Revolution* (University of Saskatchewan), published with GitHub Pages.

- `index.html`: landing page
- `spreadsheets/`: spreadsheets workshop (Excel and Google Sheets), built on the [London's Ghost Acres British imports database](https://doi.org/10.5281/zenodo.3583723)
- `assets/style.css`: shared styles

Screenshots demonstrate on a stand-in example (tea, 1876) so they don't reveal the answers to the workshop questions. Answer keys are kept out of this public repository.
